# Демонстрационные тест-кейсы DiagBase

## WEB-TC-01 — Поиск существующего диагностического случая
**Предусловие:** есть заведомо существующий и доступный для поиска случай.
**Шаги:** 1) открыть страницу поиска; 2) ввести известный код или запрос; 3) отправить.
**Ожидаемо:** найденный случай доступен в результатах, данные соответствуют запросу. **Статус:** Not run.

## WEB-TC-02 — Пустая поисковая выдача
**Предусловие:** поиск доступен.
**Шаги:** 1) ввести заведомо отсутствующую комбинацию; 2) отправить.
**Ожидаемо:** понятное состояние «ничего не найдено»; интерфейс не падает. **Статус:** Not run.

## WEB-TC-03 — Мобильная адаптивность карточки
**Предусловие:** существует доступная карточка случая.
**Шаги:** 1) открыть карточку на мобильном устройстве; 2) проверить основные блоки и действия.
**Ожидаемо:** содержимое читаемо, функциональные элементы доступны, нет перекрытий. **Статус:** Not run.
