# Кейс 03 — DiagBase: план ручного тестирования веб-платформы

**Проект автора:** https://diagbase.ru/

DiagBase — веб-сервис для поиска и хранения автомобильных диагностических случаев. Этот кейс представляет **план самостоятельного QA-аудита**, а не заявление о выполненном тестировании продакшен-сайта. Реальные доступные функции, права доступа, UX-тексты и требования нужно сверить с работающим проектом перед тестированием.

## Цели
- Проверить основные сценарии поиска неисправностей.
- Проверить удобство и корректность отображения диагностических случаев.
- Проверить поведение форм, если доступно создание/редактирование случаев.
- Проверить отображение на мобильных экранах и обработку ошибочных состояний.

## Оформление результатов после запуска
Добавить таблицу «ID — сценарий — результат — ссылка на баг», среду тестирования (браузер/версия/экран), скриншоты, итоговый тест-отчёт. Не добавлять фиктивные Pass и дефекты.
