Это портфолио демонстрирует подход к тестированию в трёх продуктовых областях: ПО весовой системы бункера-перегрузчика, мобильное приложение и веб-платформа. ## Подход к тестированию

1. Определить ожидаемое поведение продукта и рисковые сценарии.
2. Составить позитивные и негативные проверки, в том числе граничные значения.
3. Зафиксировать окружение и входные данные, выполнить проверки.
4. Документировать дефекты: предусловия, шаги, ожидаемый и фактический результат, доказательства.
5. После исправления провести повторную проверку и целевой регресс.

## Статус материалов

- **Подтверждённый опыт:** области проверок Lilliani и описанные проблемы Android-приложения — со слов автора портфолио.
- **Примеры документации:** тест-кейсы и чек-листы оформлены как демонстрационные заготовки; отметка о прохождении не проставлена.
- **Не подтверждено:** конкретный баг-трекер, используемая версия приложения, устройства, измерительные допуски и количество дефектов — данные не выдуманы.

## Конфиденциальность

Не размещать без согласования внутренние трекеры, рабочие скриншоты, исходные данные клиентов, записи с реальными телефонами и email, внутренние API и схемы подключения оборудования. Для демонстрации использовать тестовые значения и собственные скриншоты общедоступных тестовых стендов.
