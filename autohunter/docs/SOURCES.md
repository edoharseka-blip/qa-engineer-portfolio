# Источники данных: что проверено и что нет

Дата исследования: 22.10.2026. Использовались только открытые страницы документации; запросов к площадкам и
сервисам с ключами не выполнялось (ключей нет). **Ни один реальный источник в этой среде на живых данных не проверен.**

| Источник | Официальный/разрешённый доступ | Что известно | Чего неизвестно | Статус в AutoHunter |
|---|---|---|---|---|
| **Авито** | Публичного API поиска объявлений для покупателей нет. Официальное API — для продавцов/партнёров (свои объявления). | Внутренние эндпоинты сайта существуют, но их использование = обход интерфейса, рассчитанного на браузер, — **не используется**. | Условия партнёрской программы, цены, лимиты. | Только через ApiAd (ниже). |

## Что это значит для скорости (15–30 с)
* Задержка складывается из: (1) задержки самой площадки, (2) задержки агрегатора, (3) нашего интервала опроса
  (`POLL_INTERVAL_SECONDS`, по умолчанию 20 с) и (4) времени обработки (десятки миллисекунд на объявление).
* Достижимость 15–30 с зависит от (2) и лимитов ApiAd — **неизвестна до тестового периода**. Система измеряет
  `первое обнаружение − время публикации по данным источника` и показывает среднее/p95 на вкладке «Мониторинг».
* `search_transport` не возвращает время публикации → для задержки используется `time_source_created` из `parse_sync`.

## Решение по оплате (нужно ваше решение)
Я **не оформлял** подписок. Перед включением ApiAd уточните у сервиса: тариф, стоимость `search_transport` и
`parse_sync`, лимиты, SLA и допустимое использование. Параметры `APIAD_QUERIES`, `APIAD_MIN_INTERVAL_SECONDS` и
`POLL_INTERVAL_SECONDS` ограничивают расход; `parse_sync` вызывается только для *новых* ссылок и не более 5 за опрос.

## Haraba
Эксклюзивные объявления Haraba до их публикации не используются и не извлекаются. Сравнение — только по
общедоступным данным, получаемым разрешёнными способами.
