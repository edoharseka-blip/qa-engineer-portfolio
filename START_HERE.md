# Как использовать комплект

1. Откройте `resume_hh.md`, добавьте реальные даты и контакты, подтвердите название работодателя.
2. Не публикуйте материалы под реальным названием компании, если есть соглашения о конфиденциальности или запрет на публикацию. Можно переименовать кейс в «ПО весовой системы» / «Android-приложение».
3. Перед загрузкой в GitHub отредактируйте README.md, при необходимости удалите черновики и внутреннюю информацию.
4. Создайте публичный репозиторий `qa-portfolio`, загрузите папки кейсов и README.md.
5. По мере выполнения тестов добавляйте в тест-кейсы результаты и ссылки на баги, фиксируя конфигурацию окружения. Не выдавайте демонстрационные проверки за реальные результаты тестирования.
6. Ссылку на готовый репозиторий добавьте в резюме HeadHunter.
