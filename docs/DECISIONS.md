## Открытые вопросы
- Согласовать `docs/ARCHITECTURE.md`; доступ к магнитоле по ADB для исследования (только чтение).
- Телефон: на Android 10 звонки и контакты по Bluetooth закрыты для сторонних APK — ищем путь через штатное приложение KSW, иначе открываем его.
- Навигация: вариант A — Yandex MapKit внутри E90 OS (рекомендуем), B — NaviKit (нужен договор), C — запуск Яндекс Навигатора. См. `docs/NAVIGATION.md`. Условия лицензии MapKit — проверить.
- Где брать уровень масла: датчик есть у N46, путь через MCU/CAN или K+DCAN — проверить.
- Отзывы на концепты: «iDrive-стеклянный» вариант с виртуальным контроллером под экраном — «не нравится вообще»; M-спорт с тахометром — «сделай минималистичнее»; затем запрошены 10 вариантов и новая главная с машиной и полезными функциями.
