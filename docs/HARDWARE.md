## Источники данных

### 1. MCU магнитолы (штатный CAN, без доп. железа) 🔎
По библиотеке KswCarData MCU отдаёт в Android: текущую и среднюю скорость, обороты, температуру за бортом, топливо, запас хода, средний расход, двери, ручник, ремень, статус Bluetooth. Кнопки и крутилка iDrive приходят как события MCU (см. KSW-ToolKit).
Чего, похоже, нет: температура ОЖ и масла, коды ошибок.
**Проверка:** поставить KSW-ToolKit → монитор MCU → крутить iDrive, открыть дверь, включить фары, записать, что приходит.

### 2. Кабель K+DCAN в USB магнитолы (OBD) 🔎
- USB, чип FTDI, с переключателем K-line/D-CAN — подходит при любом месяце выпуска.
- В заводских настройках должен быть включён `USB_HOST`.
- Протокол BMW: KWP2000 поверх D-CAN (или DS2/K-line для ранних). Опора — открытый EdiabasLib / Deep OBD.
- Даёт: стандартные OBD-данные мотора (ОЖ, обороты, нагрузка, впуск, коррекции), ошибки, BMW-данные, сброс CBS.
- Файлы SGBD BMW в проект не встраиваем — реализуем нужные запросы напрямую.

### 3. USB-CAN «только слушать» на K-CAN (опция) 🔎
CANable / ESP32 + трансивер, режим listen-only. Видно всё, что ходит по кузовной шине. Нужна аккуратная врезка.

## Сброс ТО (CBS)
- Кнопкой на щитке — бесплатно, но на части E90 2007 с CCC не срабатывает (по форуму).
- Программно — через OBD (кабель K+DCAN). Байты команды снять в логе Deep OBD / Tool32 при сбросе на этой машине, затем реализовать с подтверждением.
