# Навигация: интеграция Яндекс Карт (черновик v0.1)

Цель владельца: карта на главной выглядит как «облако» с размытыми краями. Нажатие на неё не открывает навигатор, а даёт управлять маршрутом прямо на главном экране.

Обозначения: ✅ известно, ⚪ проверить (документация, договор, магнитола).

## 1. Главный вывод
Приложение «Яндекс Навигатор» нельзя встроить в окно нашего лаунчера. Это отдельное приложение, а Android не даёт показывать чужое окно внутри своего экрана без системных прав. Поэтому карта на главной — это **Yandex MapKit SDK внутри E90 OS**: мы сами рисуем карту, строим маршрут и показываем манёвры.

## 2. Варианты

| | Что даёт | Плюсы | Минусы |
|---|---|---|---|
| **A. MapKit (полная версия)** — рекомендую для старта | Карта, поиск, подсказки адресов, построение автомаршрута с манёврами и пробками | Всё на главной, наш дизайн, облако | Ведение по маршруту (пересчёт, голос) пишем сами ⚪; условия бесплатного использования и лимиты ⚪ |
| **B. NaviKit (навигационный SDK Яндекса)** | Полноценное ведение: голос, пересчёт, камеры | Качество как у Навигатора | Коммерческий продукт, нужен договор с Яндексом ⚪ |
| **C. Запуск Яндекс Навигатора** | Открыть приложение с готовым маршрутом по ссылке `yandexnavi://…` | Просто, без SDK | Уходим с главной — владелец этого не хочет; часть ссылок требует подпись и ключ от Яндекса ⚪ |

Предложение: делаем **A**. Вариант **C** оставляем как запасной: кнопка «В Навигаторе» в настройках, выключена по умолчанию. К **B** вернёмся, если не хватит самодельного ведения.

## 3. Как работает на главной (прототип `design/prototype.html`)
1. **Свёрнуто:** карта без рамки, края растворяются в фоне. Поверх — «Куда едем?» или текущий манёвр и время прибытия. Переключение с музыкой — вкладки или свайп.
2. **Нажатие на карту:** фото машины уезжает, облако расширяется на весь главный экран (края по-прежнему мягкие). Появляются поиск, быстрые места, +/−, «где я», «Свернуть». Карту можно двигать пальцем.
3. **Маршрут:** выбрали место → показываем время и км → «Поехать» → манёвр крупно + «Завершить».
4. **Док «Навигация»** открывает этот же развёрнутый режим на главной, а не отдельное приложение.
5. **Крутилка:** курсор ходит по кнопкам, Esc/BACK — закрыть список, затем «Свернуть».

## 4. Техника (для kotlin-specialist / mobile-developer)
- **Размытые края.** Карта MapKit рисуется через OpenGL (обычно SurfaceView), и маска Compose к ней не применяется. Делаем иначе: поверх карты рисуем градиенты цвета фона по краям (радиальный + по сторонам). На вид то же «облако», работает с любым видом карты. Если MapKit умеет рендер в TextureView ⚪, можно и честную маску.
- **Стиль карты.** Тёмный стиль через JSON-стиль MapKit ⚪: приглушённые дороги, синий маршрут под наш акцент, без лишних POI.
- **Интерфейс в коде** (всё железо и сервисы — через интерфейсы с демо-реализацией):
  ```kotlin
  interface NavigationEngine {
      val state: StateFlow<NavState>            // Idle / Preview(route) / Guiding(maneuver, eta)
      suspend fun suggest(query: String): List<Place>
      suspend fun buildRoute(to: Place): Route
      fun start(route: Route); fun stop()
  }
  // DemoNavigation — сейчас; MapKitNavigation — вариант A; NaviKitNavigation — если будет договор
  // ExternalNavigator — запасной запуск Яндекс Навигатора / Google Maps
  ```
- **Ведение по маршруту (вариант A):** берём из маршрута MapKit список манёвров ⚪ и сравниваем с GPS: «через 300 м направо», пересчёт при сходе. Голос — Android TextToSpeech, громкость поверх музыки.
- **Ключ API:** получить в кабинете разработчика Яндекса; не хранить в открытом виде в репозитории.
- **Без интернета:** карта работает из кэша; офлайн-карты и офлайн-маршруты в MapKit ⚪.
- **Snapdragon 625:** ограничить частоту кадров в свёрнутом режиме, без 3D-зданий, карту пересоздавать не при каждом переходе.

## 5. Безопасность в движении
- Набор адреса с клавиатуры — только на стоянке (скорость из MCU/GPS ниже порога). В движении — быстрые места и недавние.
- Кнопки крупные, 1–2 касания до старта маршрута.

## 6. Что проверить / решить
- ⚪ Условия использования MapKit: бесплатный тариф, лимиты, требования к приложению. Нужен ли договор для личного использования в одной машине.
- ⚪ Какие данные о манёврах отдаёт маршрут MapKit и хватит ли их для ведения.
- ⚪ Офлайн-карты в MapKit.
- ⚪ GPS магнитолы: точность и частота, работает ли в тоннелях и под эстакадами.
- 🟠 Решение владельца: вариант A (рекомендую), B или C.
