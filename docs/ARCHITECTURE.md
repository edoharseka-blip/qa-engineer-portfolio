# E90 OS — структура проекта и план источников данных (v0.1, на согласование)

Основа — пакет «iDrive Heritage» (`docs/UI_BRIEF_HERITAGE.md`, референсы в `design/reference/heritage/`).
Кликабельный прототип всех 7 экранов: `design/prototype.html`.

Обозначения: 🟢 работает сразу · 🟡 работает при разрешении пользователя · ⚪ нужно исследовать на магнитоле · 🔴 недоступно стороннему APK

## 1. Что ставим
- Отдельный APK `e90os`, обычная установка. **MCU не прошиваем, системный образ не меняем, заводские приложения KSW не удаляем.**
- Приложение объявлено как домашний экран (HOME), но **по умолчанию не становится лаунчером**: включает пользователь в «Система → Запускать E90 OS при включении».
- Возврат к штатному KSW: кнопка в «Система» и плитка в «Приложениях». Пакет штатного лаунчера определим на магнитоле командой `adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME`.

## 2. Структура проекта
```
e90os/
├─ app/                         Activity-лаунчер, навигация между разделами, DI
│  └─ ui/
│     ├─ shell/                 TopBar (бренд, время, масло, АКБ, DEMO) · SideMenu (6 разделов, косой край) · ContentHost
│     ├─ screens/               home · navigation · music · phone · apps · vehicle · settings
│     ├─ components/            DemoBadge, NoDataValue, IconTile, ListRow, Slider, Switch, RotaryFocus
│     └─ theme/                 цвета (#0B0E12, акцент #F28A24), шрифты, размеры под 8:3
├─ core/model/                  Value<T> = Live(v, source) | Demo(v) | NoData(reason)
├─ core/data/                   интерфейсы источников + Demo-реализации
│  ├─ VehicleDataSource         температура, запас хода, топливо, двери, масло, АКБ
│  ├─ MediaSource               текущий трек, play/pause/next/prev, прогресс
│  ├─ PhoneSource               подключённый телефон, вызовы, контакты, набор
│  ├─ NavigationSource          маршрут, манёвр, ETA; выбор навигатора
│  ├─ AppsRepository            установленные приложения, которые можно запустить
│  └─ SystemControls            яркость, громкость, Bluetooth, возврат к KSW
├─ platform/android/            реализации на API Android 10
├─ platform/ksw/                реализации через KSW/MCU — после исследования (⚪)
└─ platform/obd/                K+DCAN по USB — по желанию, позже
```
Стек: Kotlin, Jetpack Compose, Gradle Kotlin DSL, minSdk 29 (Android 10), только горизонтальная ориентация.

**Каркас.** Верхняя полоса и правое меню — один постоянный слой. При смене раздела меняется только содержимое слева (плавный переход без белых вспышек), а оранжевая подсветка в меню переезжает на другую строку. Фон окна тёмный уже в теме запуска, чтобы не было белой вспышки на старте.

**Честные данные.** Каждое значение — `Live`, `Demo` или `NoData`. `Demo` всегда с плашкой DEMO, `NoData` показывает «Нет данных». Переключатель «Демо-данные» в «Система» выключает все демо-значения сразу (уже в прототипе).

| Яркость | системная настройка, разрешение «Изменение системных настроек» | 🟡 ⚪ (у KSW подсветкой может управлять MCU) |

## 4. Поведение системы
- **Кнопка «Назад»** (аппаратная или на руле, через KSW): закрывает подстраницу, потом возвращает на главную. На главной ничего не делает.
- **После сна (ACC off → on):** экран восстанавливается в том же разделе, данные переподписываются, без перезапуска.
- **Крутилка:** фокус-навигация по всем элементам (повороты/наклоны), подсветка фокуса — оранжевая рамка.
- **Разрешение:** референсы 2048×768 (8:3). Реальный размер и плотность узнаём на магнитоле (`adb shell wm size`, `wm density`); вёрстка в dp, без растягивания картинок.
- **Производительность Snapdragon 625:** без тяжёлых эффектов размытия, анимации 200–350 мс, карта — с ограничением частоты кадров.
