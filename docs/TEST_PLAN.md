# План проверок (ведёт qa-expert)

## Без машины (демо-режим)
- [ ] Приложение запускается на 1280×480 и 1920×720, только горизонтально
- [ ] Все экраны открываются из дока и с крутилки, нет «тупиков»
- [ ] Каждая кнопка что-то делает или честно показывает статус
- [ ] Демо-данные помечены как демо
- [ ] Возврат к заводскому лаунчеру работает

## В машине — чек-лист для владельца
1. Поставить APK, выбрать E90 OS главным экраном.
2. Покрутить iDrive: рамка фокуса ходит по экрану, нажатие срабатывает.
3. Открыть водительскую дверь: дверь подсвечивается на силуэте.
4. Включить фары: включается ночная тема (если выбрано «авто»).
5. Проехать 1 км: скорость и поездка меняются.
6. Вернуть заводской лаунчер через Настройки → Заводской интерфейс.

## Безопасность (обязательно перед каждым релизом)
- [ ] Без подтверждения владельца в машину не уходит ни одной команды записи
- [ ] Сброс ТО / стирание ошибок: экран подтверждения → отправка → перечитка → результат
- [ ] При обрыве кабеля приложение не зависает и показывает статус
