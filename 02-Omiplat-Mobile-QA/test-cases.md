# Демонстрационные тест-кейсы — Android

## MOB-TC-01 — Отказ от некорректного email
**Предусловие:** пользователь авторизован, доступен экран смены email.
**Шаги:** 1) Ввести `qa@example.`; 2) нажать «Продолжить».
**Ожидаемо:** форма отклоняет адрес и не переходит к подтверждению. **Статус:** Not run по этому документу; аналогичная проблема ранее обнаружена пользователем.

## MOB-TC-02 — Указание текущего email
**Предусловие:** текущий email уже задан в профиле.
**Шаги:** 1) Открыть смену email; 2) ввести тот же адрес; 3) продолжить.
**Ожидаемо:** интерфейс информирует об отсутствии изменения или блокирует ненужное подтверждение, согласно требованиям. **Статус:** Not run по этому документу.

## MOB-TC-03 — Проверка длины SMS-кода
**Предусловие:** открыт экран подтверждения телефона.
**Шаги:** 1) Вставить строку из цифр длиннее допустимого значения; 2) проверить ввод и отправку.
**Ожидаемо:** ввод ограничен или корректно отклонён, ошибка понятна. **Статус:** Not run по этому документу.
