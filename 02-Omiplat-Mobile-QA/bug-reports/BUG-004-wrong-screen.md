# BUG-004 — После некорректного SMS-кода открывается неподходящий экран

**Основа:** обезличенный дефект, ранее обнаруженный автором.  
**Экран:** подтверждение SMS в сценарии изменения email.

**Шаги:** 1) открыть экран SMS-подтверждения; 2) ввести неверный или чрезмерно длинный код; 3) отправить.

**Ожидаемо:** корректная ошибка верификации без необоснованного перехода; точное поведение согласовывается с требованиями.

**Фактически:** приложение открывает экран подтверждения номера телефона (по наблюдению автора).

**Версия/статус исправления:** не установлены. **Серьёзность:** на оценку команды.
