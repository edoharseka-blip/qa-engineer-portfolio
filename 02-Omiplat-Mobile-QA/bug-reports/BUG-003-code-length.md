# BUG-003 — Нет ограничения длины полей кодов подтверждения

**Основа:** обезличенный дефект, ранее обнаруженный автором.  
**Экран:** подтверждение email и SMS.

**Шаги:** 1) открыть экран ввода кода; 2) набрать или вставить число цифр больше длины кода, установленной спецификацией.

**Ожидаемо:** поле ограничивает ввод или валидирует его согласно требованиям.

**Фактически:** поля позволяют ввести произвольное количество цифр (по наблюдению автора).

**Версия/статус исправления:** не установлены. **Серьёзность:** на оценку команды.
