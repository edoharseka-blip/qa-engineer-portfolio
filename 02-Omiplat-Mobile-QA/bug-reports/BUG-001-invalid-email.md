# BUG-001 — Недостаточная проверка формата email

**Тип:** пример обезличенного баг-репорта для портфолио.
**Платформа:** Android.
**Раздел:** профиль пользователя.

**Предусловие:** открыт экран изменения электронной почты.

**Действия:**
1. Ввести адрес электронной почты, не соответствующий правилам формата.
2. Нажать кнопку продолжения.

**Ожидаемый результат:** пользователь получает сообщение о некорректном вводе, дальнейший шаг недоступен.

**Фактический результат:** форма разрешает переход к следующему экрану.

**Версия и статус исправления:** не указаны.
**Серьёзность:** уточняется командой.
**Примечание:** пример основан на наблюдении автора; служебные данные удалены.
