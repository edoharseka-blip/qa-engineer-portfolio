# E90 OS — инструкции для Claude

Собственная мультимедийная оболочка (Android-лаунчер) для Android-магнитолы KSW в BMW E90 320i 2007 года (N46B20, 150 л.с.). Владелец общается по-русски.

## С чего начинать любую сессию
1. Прочитай `docs/ROADMAP.md` (где мы), `docs/DECISIONS.md` (что решено), `docs/PAGES.md` (что делаем).
2. Работу ведёт агент **project-manager**: он раздаёт задачи команде из `.claude/agents/` и в конце пишет отчёт владельцу.

## Команда (`.claude/agents/`)
| Агент | За что отвечает |
|---|---|
| project-manager | план, статусы, решения, отчёты владельцу |
| product-manager | карта экранов и функций (`docs/PAGES.md`) |
| ux-researcher | удобство в машине, крутилка iDrive, `docs/UX_REVIEW.md` |
| ui-designer | визуальный дизайн, `design/DESIGN_SYSTEM.md` |
| kotlin-specialist | архитектура и код на Kotlin/Compose |
| mobile-developer | Android-платформа: лаунчер, медиа, USB, навигаторы |
| embedded-systems | CAN через MCU KSW, OBD/KWP2000, сброс ТО |
| iot-engineer | адаптеры, Bluetooth, аудио-переключатель |
| qa-expert | `docs/TEST_PLAN.md`, чек-листы «в машине» |
| test-automator | автотесты без машины |

Навыки дизайна: `.claude/skills/` (mobile-android-design, visual-design-foundations, interaction-design, accessibility-compliance).

## Правила проекта (обязательны для всех)
1. **Безопасность машины.** По умолчанию только чтение. Любая запись в блоки (сброс ТО, стирание ошибок) — только явным действием владельца, с экраном подтверждения и перечиткой результата. Никаких управляющих CAN-команд.
2. **Прошивка.** Не трогать загрузчик, разделы, MCU, «Протокол CAN» и «Car Display» в заводских настройках. Сначала резервная копия и способ восстановления. Чужие прошивки не ставить.
3. **Честный интерфейс.** Нет декоративных кнопок. Если функция недоступна — показываем её реальный статус. Демо-данные всегда помечены.
4. **Не перегружать интерфейс** — пожелание владельца.
5. **Путь назад** к заводскому лаунчеру и настройкам Android есть всегда.
6. **Решения владельца** (дизайн, функции, покупки) не принимаем за него — предлагаем варианты и записываем выбор в `docs/DECISIONS.md`.
7. Без логотипов и фирменных элементов BMW / BMW M — дизайн собственный.

## Технологии
Kotlin, Jetpack Compose, Gradle Kotlin DSL, minSdk 29 (Android 10), горизонтальная ориентация, 1280×480 и 1920×720. Всё железо — через интерфейсы с демо-реализацией.
